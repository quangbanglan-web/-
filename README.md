# Интерактивная доска

Локальное приложение интерактивной доски с Dashboard, изоляцией уроков по предметам и сохранением в SQLite.

## Требования

- Node.js 22.13 или новее
- npm

## Установка и запуск на Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
npm install
npm start
```

## Установка и запуск на Linux

Откройте терминал в папке проекта и выполните:

```bash
npm install
npm start
```

Команда `npm start` сначала собирает фронтенд, затем Express раздаёт его на <http://localhost:3000>. SQLite автоматически создаёт файл базы данных `data.db` в корне проекта. Чтобы изменить порт, задайте переменную окружения `PORT` перед запуском.

В главном меню выберите предмет, чтобы увидеть только его уроки, создать новую доску, переименовать или удалить существующую. Предметы можно добавлять в левом меню. На холсте название редактируется нажатием на него; изменения сохраняются кнопкой или автоматически раз в минуту отдельно для каждой доски.

Сохранённую доску можно открыть напрямую по адресу `http://localhost:3000/?id=<id>`. В режиме разработки с Vite используйте `npm run dev`.
